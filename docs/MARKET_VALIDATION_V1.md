## Конкурентный вывод

Насыщено:
- generic prompt packs;
- простые PDF launch guides;
- простые Notion launch planners;
- giant template bundles;
- обещания быстрых доходов.

Менее commodity:
- integrated workflow;
- local-first app;
- calculators + decision support;
- product-specific generation;
- one source of truth для product profile;
- reusable launch assets;
- export/copy workflows.

## Product differentiation hypothesis

LAUNCH OS не должен продаваться как «ещё 500 промптов».

Основная ценность:
1. Один Product Profile.
2. Из него строятся Validation, Offer, Pricing, Sales Page и Content.
3. Каждый результат можно редактировать и экспортировать.
4. Local-first режим без обязательной подписки.
5. Notion companion — optional, не обязательная зависимость.
6. AI не обещает результат сам по себе; система структурирует работу пользователя.

## MVP

Первый тестируемый MVP:
- Product Profile
- Idea Score
- Validation Canvas
- Offer Builder
- Pricing Calculator
- Sales Page Builder
- local persistence
- export to Markdown/TXT/JSON
- clean mobile UI

Не строим пока:
- аккаунты;
- backend;
- subscription;
- complex AI API integration;
- social integrations.
