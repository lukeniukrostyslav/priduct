# LAUNCH OS — Visual Design System V1

## Approved visual direction
The generated Russian dashboard mockup is the visual reference for LAUNCH OS V1.

Core characteristics:
- premium desktop SaaS dashboard
- dark navy left navigation
- bright workspace canvas
- rounded cards
- restrained blue/purple accent system
- strong hierarchy and generous spacing
- responsive mobile layout
- Russian UI shown in the reference; all UI must also support EN, IT, DE and FR
- local-save status and export visible at the top
- Online Research is a first-class module
- no Notion references or Notion features

## Main navigation
1. Идея / Idea
2. Проверка / Validation
3. Продукт / Product
4. Предложение / Offer
5. Цена / Pricing
6. Исследование / Research
7. Страница продаж / Sales Page
8. Контент / Content
9. Запуск / Launch
10. Развитие / Growth

## Workspace layout
- sidebar: product workflow + projects + settings + language selector
- top bar: project name, local-save state, export
- hero: current workflow stage
- main workspace: current module
- right column: quick actions, online research, contextual resources
- lower area: score/progress and next steps

## Interaction principles
- every important action has visible feedback
- local persistence is explicit
- exports are explicit
- offline core functions must remain usable
- online research opens user-controlled web search; no paid search API required
- no fake AI or fake live data

## Responsive behavior
Desktop:
- sidebar + two/three-column workspace

Mobile:
- collapsible navigation
- single-column cards
- sticky primary action
- research buttons remain accessible

## Localization
EN, IT, DE, FR, RU are product languages. Text must come from a localization dictionary rather than duplicated hard-coded screens.
